## Local Development
1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.
3. API keys are not required for local development. Ask AAYU uses its built-in knowledge fallback until you configure a supported provider key in the server-side environment.

When you add a provider key later, keep it in `.env` locally or in the hosting provider's server-side environment variables. Never expose API keys in browser code or commit real keys to the repository.

## Google Search
The production SEO metadata, person/organization structured data, `robots.txt`, and sitemap use `https://adumate.in/` as the canonical public URL. Deploy the site to that stable HTTPS domain before requesting indexing; a temporary tunnel URL is not a substitute for the canonical domain.

After deployment, verify the domain in Google Search Console using a DNS TXT record, then submit `https://adumate.in/sitemap.xml` and inspect `https://adumate.in/`. Verification requires access to the domain's DNS or hosting account and must be completed in Search Console.
